Install

安裝

  1. Keep the original LIBs in your FA folder: FA_1.LIB, FA_2.LIB, FA_4B.LIB, FA_4D.LIB (and _HUD.LIB if you have it).
  2. Remove every older JKPFA or JKP LIB: FA_JKPFA_*.LIB, FA_JKPFA54_*.LIB, _MAP.LIB, _MUSIC.LIB, older JKP6xx_*.LIB. Two versions must never be loaded together.
  3. Unzip JKP600.zip and copy the eight JKP600_*.LIB into the FA folder.
  1. FA 目錄裡保留原版 LIB：FA_1.LIB、FA_2.LIB、FA_4B.LIB、FA_4D.LIB（有 _HUD.LIB 的話也留著）。
  2. 移走所有舊版 JKPFA 或 JKP 的 LIB：FA_JKPFA_*.LIB、FA_JKPFA54_*.LIB、_MAP.LIB、_MUSIC.LIB、較舊的 JKP6xx_*.LIB。兩個版本絕對不能同時載入。
  3. 解壓 JKP600.zip，把 8 個 JKP600_*.LIB 複製到 FA 目錄。

Tested with the original FA.EXE 1.02f and with FA_BIG: mission builder and missions work. The LIBs can also be checked in your browser on the LIB rules page.

已用原版 FA.EXE 1.02f 和 FA_BIG 測試：任務建立和任務都正常。也可以在 LIB 規則頁用瀏覽器檢查這些 LIB。

If one of your own loose files does not seem to take effect: for a name that exists in several places, FA uses the copy whose file (LIB or loose file) has the newest date. A loose file you edit after installing JKP wins again.
如果你自己的散檔好像沒有生效：同一個檔名出現在好幾個地方時，FA 會用檔案日期最新的那一份（LIB 檔或散檔）。安裝 JKP 之後再改過的散檔，又會重新生效。

Version numbers

版本號

JKP600→JKP601→JKP602…JKP699→JKP700

Every build gets the next number and the LIBs carry it (JKP601_A.LIB…), so a higher number is always newer and you can see at a glance which version is installed. Every release is kept in lib_release on GitHub.

每次編譯都用下一個號碼，LIB 檔名也帶著它（JKP601_A.LIB…），所以號碼越大越新，一眼就看得出裝的是哪一版。每一版都保留在 GitHub 的 lib_release。
