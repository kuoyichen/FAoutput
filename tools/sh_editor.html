Save options


Saving only rewrites bytes in place, so the file layout, jumps and relocations stay exactly as they were. New vertex groups (F-14N nose, EA-18G stores, CODE grown by 0x1000) load and save normally.

Reference images

Width is in vertex units. A new image is scaled to the model and placed beside it, 10 units away (Fit does it again). It shows in the matching Ortho view, or always if ticked.

Drag a selected point to move the selection (snaps to the grid; always along X, Y or Z: the locked axis, or in Auto the one closest to the mouse)
