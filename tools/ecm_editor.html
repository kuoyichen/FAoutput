How FA.EXE uses it
      
    
        
  • An ECM is loaded on a PT hardpoint like a weapon (the hardpoint's default type names the .ECM). One aircraft can carry several, e.g. A-10A: F18.ECM + A10.ECM.
    • 
        
  • J key turns the jammers on: radar jamming needs an ECM with Jammer Installed, IR jamming one with IR Jamming. The first matching hardpoint wins.
    • 
        
  • Missile Miss % lowers an incoming missile's per-tick chance of keeping its lock: strength × (100 − miss%) / 100. Radar for radar missiles, IR for heat seekers.
    • 
        
  • Increase to RCS / ICS is added to the jamming aircraft's radar / IR signature. A radar jammer also makes the aircraft visible to anti-radiation missiles.
    • 
        
  • CW / Pulse / Frequency Hop decide which radar seekers the RCS increase applies to (matched against the seeker's own bits).
    • 
        
  • Max Detect Cone is read as a range in nautical miles: inside it, a hostile jammer shows as jamming on the player's radar display.
    • 
        
  • Jamming protects only the aircraft carrying it; an EA-6B does not shield its wingmen.
    • 
      

      
    
        
  • ECM 和武器一樣裝在 PT 掛點上（掛點的預設類型寫 .ECM 檔名）。一架飛機可以掛好幾個，例如 A-10A：F18.ECM + A10.ECM。
    • 
        
  • J 鍵開啟干擾：雷達干擾要有勾選 Jammer Installed 的 ECM，紅外線干擾要有勾選 IR Jamming 的 ECM。用第一個符合的掛點。
    • 
        
  • 飛彈失誤 % 降低來襲飛彈每一刻保持鎖定的機率：強度 ×（100 − 失誤%）/ 100。雷達值對雷達飛彈，紅外線值對熱追蹤飛彈。
    • 
        
  • RCS / ICS 增加量加在干擾機自己的雷達／紅外線訊號上。開雷達干擾也會讓反輻射飛彈看得到這架飛機。
    • 
        
  • CW / 脈衝 / 跳頻決定 RCS 增加量對哪些雷達導引頭有效（和導引頭自己的位元比對）。
    • 
        
  • 最大偵測錐被當成海浬距離：在這個距離內，敵方干擾機會在玩家雷達畫面上顯示為干擾。
    • 
        
  • 干擾只保護掛載它的飛機本身；EA-6B 不會保護僚機。
    •
