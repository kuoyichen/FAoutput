FA sound file format

FA sound files have no header: the whole file is raw 8-bit unsigned mono PCM (128 = silence). FA.EXE passes the file straight to the Miles sound library as DIG_F_MONO_8, unsigned, and picks the playback rate from the extension only:

ExtensionGame valueRate
.11K0x10011025 Hz
.8K0xBA8010 Hz
.5K0x805512 Hz

(Rate = 11025 × value / 256, worked out from FA.EXE at 0x4336E1 and 0x435A1D. Any other extension is not played.) File size in bytes = number of samples, so 1 second of .11K is 11,025 bytes.

Name prefixes used by the factory files: & sound effects (&AFTBURN.11K, &RWRLOCK.5K), ^ voices and radio calls (^EJECT.5K), AIR###.11K music. Names must be 8.3 and upper case. To put a new or replaced sound in the game, add it to a LIB with tools/falib.py (folder 11K/, 5K/ or 8K/).

Converting from MP3: the sound is mixed to mono, resampled with a low-pass filter (so no aliasing), and rounded to 8 bits. Parts you have not changed in an FA file you opened stay byte-identical when saved in the same format.

FA 聲音檔沒有檔頭：整個檔案就是原始的 8 位元無號單聲道 PCM（128 = 無聲）。FA.EXE 直接把檔案交給 Miles 音效函式庫，格式 DIG_F_MONO_8、無號，只依副檔名決定播放取樣率：

副檔名遊戲內數值取樣率
.11K0x10011025 Hz
.8K0xBA8010 Hz
.5K0x805512 Hz

（取樣率 = 11025 × 數值 / 256，由 FA.EXE 0x4336E1 與 0x435A1D 解出。其他副檔名不會播放。）檔案大小（位元組）= 取樣數，所以 1 秒的 .11K 是 11,025 位元組。

原廠檔名的前綴：& 音效（&AFTBURN.11K、&RWRLOCK.5K），^ 語音與無線電（^EJECT.5K），AIR###.11K 音樂。檔名必須是 8.3 大寫。要放進遊戲，用 tools/falib.py 打包進 LIB（放在 11K/、5K/ 或 8K/ 資料夾）。

從 MP3 轉換時：先混成單聲道，再用低通濾波重新取樣（避免疊頻），最後轉成 8 位元。開啟的 FA 檔中沒有修改的部分，用相同格式儲存時會保持逐位元組相同。
