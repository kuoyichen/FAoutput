FA_BIG

A patched FA.EXE (version 1.02f) that starts with far more .LIB archives and shape files in the game folder. The original game silently overflows its tables and dies at startup with “Not enough memory.” FA_BIG gives those tables much more room.

修改過的 FA.EXE（1.02f 版），讓遊戲目錄可以放更多 .LIB 和外形檔。原版的表格滿了不會檢查，直接寫壞記憶體，啟動時就跳出 「Not enough memory.」 結束。FA_BIG 把這些表格放大很多倍。

At startup FA scans its folder and every .LIB inside it, and writes one 35-byte entry per file into a file index. Move the sliders to see what each EXE does with your folder.

Duplicates count too: every copy of a file, in any LIB or loose, takes an index slot during the scan before duplicates are removed.

重複的檔案也算：同名檔案不管在哪個 LIB 或是散檔，掃描時每一份都先佔一格，之後才去掉重複的。

Same file name in several places

同名檔案放在好幾個地方

After the scan FA sorts the index by name, then by date and time (newest first, compared to the minute), and keeps only the first of each name. A file inside a LIB gets the LIB file's own date. Change the dates below to see which F14.SH the game would load.

掃描完後，FA 會依檔名排序，再依日期時間排序（新的在前，比到分鐘），每個檔名只留第一個。LIB 裡的檔案用的是那個 LIB 檔本身的日期。改改下面的日期，看看遊戲會載入哪一個 F14.SH。

The copies that lose cost nothing after startup: they are dropped from the index, never loaded, and use no object or cache slot. Only disk space, and a LIB stays memory-mapped as a whole.

沒被選中的那幾份，啟動後就不再佔東西：它們從索引移除、不會被載入，也不佔物件或快取的格子。只佔硬碟空間，另外 LIB 整個檔案會一直映射在記憶體位址空間裡。

Only 63 bytes of code and one new empty section (.rmcache) differ from 1.02f. Four bytes in unused padding make the CRC32 equal to the original, so launchers that check the 1.02f CRC still accept it.

跟 1.02f 相比只改了 63 個位元組的程式碼，加上一個新的空區段（.rmcache）。另外在沒用到的空白處改了 4 個位元組，讓 CRC32 跟原版一樣，所以會檢查 1.02f CRC 的啟動器也能用。

Download and install

下載與安裝

  1. Make sure you have FA 1.02f. FA_BIG is built from the 1.02f FA.EXE.
  2. Back up your FA.EXE, for example rename it to FA_ORIG.EXE.
  3. Download FA_BIG.ZIP and unzip it into the game folder. It contains one file, FA.EXE.
  4. Keep the name FA.EXE. The game looks for <exe name>.SMS, which shapes need. If you rename the EXE (for example FA_BIG.EXE) it stops with “Not enough memory.” right away.
  5. Start the game as usual, directly or with your launcher.
  1. 確認你的 FA 是 1.02f 版。FA_BIG 是用 1.02f 的 FA.EXE 改的。
  2. 先備份原本的 FA.EXE，例如改名成 FA_ORIG.EXE。
  3. 下載 FA_BIG.ZIP，解壓到遊戲目錄。裡面只有一個檔案：FA.EXE。
  4. 檔名一定要是 FA.EXE。遊戲會用自己的檔名去找 <檔名>.SMS，外形檔需要它。改成別的名字（例如 FA_BIG.EXE）會馬上跳「Not enough memory.」。
  5. 照平常方式啟動遊戲，直接執行或用你的啟動器都可以。
To go back, delete the new FA.EXE and rename FA_ORIG.EXE back to FA.EXE. Mission files and settings are not touched.
要還原的話，刪掉新的 FA.EXE，再把 FA_ORIG.EXE 改回 FA.EXE。任務檔和設定都不受影響。

從發布 #7 起，ZIP 裡的 FA.EXE 也包含較小的機砲判定框：看改了什麼。

想自己做：GitHub 上的 FA_BIG 目錄有 fa_patch_limits.py（修改程式，列出每個位址）和 crc_match.py（CRC 修正）。
