# FAlogger

FAlogger records Fighters Anthology missions while you fly. You can then replay them in 3D in your browser, ACMI style.

| File | What it is |
| --- | --- |
| `falogger.zip` | `falogger.exe` and `falogger.py` together; download this one |
| `falogger.exe` | Windows program; double-click it and fly |
| `falogger.py` | the same program as Python source (Python 3.8+, Windows) |

The full guide covers recording, opening the `.bin` in the replay page, every option and making a video:
https://kuoyichen.github.io/FAoutput/tools/falogger.html

The replay page is at https://kuoyichen.github.io/FAoutput/tools/fa_replay.html

The development copy of the script is `tools/falogger.py`.
