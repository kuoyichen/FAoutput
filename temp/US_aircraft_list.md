## 建議修改順序（每架做完自動接下一架）

1. 現役主力、外形對但太簡化（約 250–360 面，F-14/F-18 是 800–900）：F-15C → F-15E → F-16 → F-4 → A-10 → F-22 → F-35A/B/C（分三個外形）→ AV-8B → A-6/EA-6B → A-7 → A-4 → F-111/EF-111 → F-117 → F-5E → F-104 → F-105 → F-8 → RA-5C
2. 轟炸、支援、直升機：B-1 → B-52 → B-2 → E-2C → C-17 → AH-64 → AH-1 → UH-60/SH-60 → CH-47 → V-22 → UH-1
3. 代用外形換掉（先找 SH/ 裡較接近的外形改，例如 C130.SH 可當 C-130 的底）：U-2 → C-130 系列 → S-3 → F-23 → CH-53/HH-3 → OH-6/OH-58 → P-8 → EC-121 → 其餘韓戰時期機

每架預計：查實機資料（三視圖、照片、掛載、控制面），SH 加細節並保持 900 頂點上限，前輪單/雙輪與 3D 起落架、旋轉輪、控制面動作、後燃器動畫（有後燃器者）、折翼（艦載機）、法向量與遮擋修正、命中盒、PT 掛點與推力。
