# JKPFA6 file set: every file that goes into the JKPFA6 LIBs.
#
# [rules]  which LIB a file goes to. One line per LIB: the LIB name, then
#          file patterns (* = anything). The FIRST line that matches wins,
#          so put special cases (music) above the general ones (sounds).
#          To add a LIB, add a line. Letters G-L, N-R, T-Z are free.
# [files]  one file name per line, in any order (the tool sorts them),
#          optionally followed by the description the FA ToolKit shows.
#          To add a file to the game: put it in the repo folder named after
#          its extension (PT/, SH/, PIC/, 11K/ ...) and add its name here.
#          To drop a file: delete its line. Text after # is a comment.
#
# Build:  python tools/falib.py build LIB/JKPFA6.txt --src . --out build --toolkit
# Skill:  skill/FA_LIB_build.MD
