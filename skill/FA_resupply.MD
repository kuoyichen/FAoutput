# FA.EXE 補給（Re-Armed and Re-Fueled）邏輯

2026-11-21 靜態逆向 FA.EXE（基底 0x400000）。尚未用錄影驗證。

## 入口

- 每幀處理玩家飛機時（0x417150 一帶的地面狀態函式）：
  - `[obj+0x16F] & 0x1000` 為 0，
  - 機型 PT 不是 `~BGUN.PT`（地面砲手模式），
  - 0x411910 判定在地面上（見 FA_flight_model / 地面偵測），
  - `[obj+0x10] & 0x80`（人類玩家），
  才呼叫 **0x417530 = 補給檢查**。沒有計時器，條件一成立當幀就補。

## 0x417530 的條件（全部要成立）

| # | 條件 | 位址 / 數值 |
|---|------|------------|
| 1 | 玩家有「所屬基地」指標 `base = [obj+0x231]`（工作副本 0x50D0B1）且不為 0 | |
| 2 | 基地物件索引 `base+0xE6`（u16）不為 0 | |
| 3 | 任務允許補給：`allowrearmrefuel` 旗標 byte 0x54BD8C ≠ 0 | 任務檔指令 `allowrearmrefuel N`，任務重設時預設 1（0x4807CF） |
| 4 | （僅連線對戰 0x5528BC≠0）基地所屬隊伍 `[baseObj+1]&0xFF000000` 的目標尚未全滅（0x485260） | |
| 5 | 基地與玩家同陣營：`([baseObj+9] ^ [obj+9]) & 0x80 == 0` | |
| 6 | 速度剛好為 0：`[obj+0x34]`（0x50CEB4）== 0 | 完全停住 |
| 7 | 與基地補給點距離 < **1600 ft**：`dist(obj+0x11, base+0xAA) < 0x64000` | 距離是近似值 max + mid/4 + min/4（含高度，0x4C66CC） |
| 8 | 油料缺口 > **350 lb**（0x417620）：內油容量 `[PLANE+0xAB]`(0x50D3CD) + 掛載副油箱容量總和 − (內油 `[obj+0x1FC]`(0x50D07C) + 副油箱剩油)>>8 > 0x15E | 單位 lb，油量欄位是 lb<<8 |
| 9 | 至少有一個掛點的數量少於任務開始時的數量（0x453B90；連線版 0x453F90） | |

成立後：0x453C50（連線版 0x454060）還原掛載，再以 0x48E920 顯示訊息 139
「 Plane Re-Armed and Re-Fueled」（發話者 = 基地物件）。

**重點：第 8 和第 9 條要同時成立。** 依程式碼，只耗油沒用武器、或只用武器但油缺口 ≤ 350 lb，都不會補給（待遊戲內驗證）。

## 補給點在哪裡：SH 具名點 0x11

- 「基地」不是 SUPPLY 物件。程式碼完全沒檢查 SUPPLY.OT/SUPPLY.SH。
- 基地表 0x58B850，最多 40 筆（數量 u16 0x58B828），每筆 0x134 bytes；`+0xE6` = 基地物件索引，`+0xE8` = 航艦旗標。
- 只有兩種物件會登記成基地（0x4BA800）：
  - 跑道類 `_STRIPProc`（OT/STRIP*.OT、DTSTRP）：初始化 0x4BE2A0
  - 船艦（航艦）：初始化 0x4BDB30（裡面還會比對 kiev/clem/wasp/nimz/olekma/sacram.NT）
- 基地記錄的每個點 = SH F2 表裡的 0xC0 具名點（0x42E100 依 id 找）。點紀錄 0x12 bytes：`+0x14` 本地座標 i16×3，`+0x1A` 世界座標 i32×3。
  - 第 8 筆（`+0xA4` 本地 / `+0xAA` 世界）= **具名點 id 0x11** → 補給距離就是量到這個點。
  - 跑道另有 0x25–0x28、0x12、0x17、0x18；航艦另有 0x17、0x13、0x18。
- 已知 0x11 點位置（F2 單位 = ft）：
  - RNWY1：x −1772, up 0..28, fwd −1700..−1680（跑道一端）
  - DTSTRP：x 0..4, fwd −472（1200 ft 土跑道的一端，1600 ft 內幾乎整條）
  - NIMZ：x −59, up 260, fwd 783（甲板上，1600 ft 內涵蓋整個甲板）
  - KIEV：x −100..−96, up −84..−90, fwd −1020
- 想把補給點移到別處：改基地 SH 的 0x11 具名點座標即可。

## 所屬基地 `obj+0x231` 怎麼決定

- 任務載入時可由任務檔指定（0x46DB65/0x46DB93：索引 0xFF = 無）。
- 飛行中（狀態 `[obj+0xE3]` 不在地面 1..0x12、進場 0x13..0x1E 範圍時）會改成**最近的友軍基地**（0x452590 → 0x4BA8E0）。
- 0x4BA8E0 選基地：同陣營、基地 typedef+9 有 0x8000（可降落）、物件存活（0x4747C0：active、HP≠0、無 0x2000 旗標），比距離（量到基地 `+0xC8` 點）。
- 所以實務上：降落停住時的基地 = 落地前最後選到的最近友軍跑道/航艦。

## 補了什麼

- 「原始掛載」在任務開始時存下（0x4538C0，0x4043D9 呼叫）：每個人類玩家的 class 2/4 物件，存每個掛點的 typedef 指標（0x5452B8 + slot*60）、數量（0x545A78 + slot*30）、內油（0x5454A8 + slot*4）；玩家物件索引表 0x545498，數量 0x545A70。連線版另存在 0x545208 / 0x5454D0 / 0x545B68 / 0x5466A8（0x453D50）。
- 還原（0x453C50）：
  - 內油 `[obj+0x1FC]` = 任務開始時的內油（不是容量上限，是起飛時的量）。
  - 每個掛點用 0x452C20 重新掛上原本的武器與數量；副油箱（class 8 GAS）重新裝滿 = 容量×數量；ECM（class 9）熱焰彈/干擾絲補滿；原本空的掛點清空（0x4527F0）。
  - **不修復損傷**（HP `obj+0x0E` 沒有動）。
- 每次補給回到任務開始的狀態，所以可以重複補給（只要條件 8、9 再次成立）。
