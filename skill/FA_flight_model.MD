# FA.EXE 飛行模型（空氣動力計算）解析筆記

2026-11-16，FA.EXE 靜態反組譯（capstone，PE base 0x400000）。
實作：`tools/fa_flight_model.js`（`FAFM`），模擬器 `tools/fa_flight.html` 的「Flight model: FA」使用它。

標記：**[確認]** 已逐行讀過組語、公式與常數都對得上；**[推測]** 從用途、數值或命名推出來，沒有完全追完。

---

## 1. 結論先講

FA 不是真的空氣動力（沒有升力係數、AoA 曲線、翼面積）。它是「質點沿飛行路徑」的模型：

1. 搖桿直接指令**負載因數 n（G）**，上限由 PT 的 **G 包線（envelope）** 在目前速度/高度允許的範圍決定。 [確認]
2. 路徑俯仰率 **q = (n − 1) × 2500 / V**（deg/s，V 單位 fps，V 最小取 125，|q| ≤ 40）。 [確認]
3. 永遠有 1 g 升力抵銷重力，所以傾斜時路徑自然下彎/轉彎（Euler 運動學）。 [確認]
4. 速度：推力隨 V/Vmax(alt) 線性下降，阻力隨 V/Vmax(alt) 線性上升，加上每 G 的誘導阻力、起落架/襟翼/減速板阻力，再加上沿路徑的重力分量。**Vmax(alt) 就是 1G 包線在該高度的右邊界**，所以最高速度由包線決定，不是由推力阻力平衡「算」出來。 [確認]
5. 低於 1G 包線左邊界（失速速度 Vs）：升力減少、機頭下沉、最後進入失速狀態。 [確認]

所以 PT 裡最重要的是：**G 包線、推力（MIL/AB）、Cd、G-drag、滾轉率表、G onset**。

## 5. 計算流程與公式

每格 dt 秒。V = 沿路徑速度（fps），alt = 高度（ft）。

### 5.1 包線與 G 限制（0x452140，每秒一次）[確認]
- 每條包線 = 一個 G 值 + 一串 (速度, 高度) 點；altIdx 指向最高點。左半邊是低速邊界，右半邊是高速邊界。
- 某高度的速度帶 [min, max] 用線性內插取得。放襟翼時 |G| ≤ 1 的包線 min × 0.75。
- 檢查順序：太慢 → 1；≥ max → 3；≥ Vne → 2；否則 0（在包線內）。
- 可用 G 上限 = 目前點仍在包線內的最大 G，再朝下一條包線依速度內插（得到小數 G）。下限同理。
- 掛載：G 限制 × (100 − 掛載% × PLANE[93] / 100) / 100。
- **Vmax(alt) = 1G 包線在該高度的 max**；**Vs = 1G 包線在該高度的 min**。
- 速度低於 2×Vs 時，G 限制與滾轉率限制都乘上 V/(2Vs)（0x476880）。

### 5.2 G 與俯仰 [確認]
- n 以 0x476950 推向 `1 + stick × (上限 − 1)`，速率 = G onset × |stick|（至少 1/4），跨越 1G 時多加 offset/2；放開搖桿以 offset 回到 1G。
- q = clamp((n − 1) × 2500 / max(V,125), ±40) deg/s，套到機體 pitch 軸。

### 5.3 滾轉與方向舵 [確認]
- 滾轉率以同一個 drive 函式推向 PLANE[19]（右）/ PLANE[18]（左），再乘 (100 − 掛載% × PLANE[94]/100)/100。
- 方向舵轉率基準 = 2500/V，乘上 rudMax/rudMin；側滑產生阻力（PLANE[39]）並讓飛機滾轉（PLANE[40]）。

### 5.4 姿態積分（0x477010、0x476AE0）[確認]
- 標準 Euler：
  - φ̇ = p + (q sinφ + r cosφ) tanθ
  - θ̇ = q cosφ − r sinφ
  - ψ̇ = (q sinφ + r cosφ) / cosθ
- 1g 升力彎曲：a = 2500/V × cosθ；θ += a(cosφ − 1)·dt；ψ += a sinφ·dt。
  平飛傾斜時只要拉 1/cosφ 的 G 就能保持高度，和真實一致。
- 低於 Vs 且未失速：機頭往下、低的那一翼繼續往下掉（0x47BB85）。
- 低速 alpha：V − Vs < PLANE[31] 時，飛行路徑在機頭下方最多 PLANE[32] 度（0x476DAF）。所以低速時機頭上揚、飛機在「沉」。

### 5.5 推力（0x47A8C0）[確認]
```
T = max(0, 2.56 × 油門% − 128 × V / Vmax) × Thrust / 256      (lb)
Thrust = PLANE[74]（AB）或 PLANE[73]（MIL）
超過 Vne 時油門項 = 0
```
油門以 PLANE[75]/[76] %/s 追上指令（0x451E80）。AB 只有油門 100% 才有效。

### 5.6 阻力（0x47A970、0x4784A0、0x47AB60）[確認]
```
t   = V × 100 / Vmax          （穿音速修正：在 366 fps 與音速之間額外調整，見 0x47AB60）
寄生 = max(16, Cd × (100 + 掛載% × PLANE[91]/100)/100 × t / 200)     ← ×1.5 若超過 Vne
誘導 = Gdrag × (100 + 掛載% × PLANE[92]/100)/100 × (|n| − 1)
     + 起落架 + 襟翼 + 減速板 + 彈艙 + 側滑阻力
D   = 寄生 × ThrustAB / 256 + 誘導 × W × t / 100 / 256                 (lb)
```
注意寄生阻力乘的是**最大推力**，所以 Cd 本質上是「最大推力的百分比」，這讓每架飛機在 Vmax 附近自然平衡。 [確認公式；這個解讀為推測]

油門 0 時，寄生阻力至少 64（爬升時）。 [確認]

### 5.7 速度積分（0x47C860）[確認]
```
先扣阻力：V -= min(加速上限, 32 × D / W) × dt   （不會讓速度反向）
再加推力與重力：V += clamp(32 × (T/W − sinθ), −減速上限, 加速上限) × dt
V 限制在 [PLANE[6], Vmax]
地面放起落架時加速上限 × 0.25
```

### 5.8 升力與下沉（0x47C980、0x47CA70、0x47CB80）[確認]
- V ≥ 海平面 Vs0 時升力 L = 1 G（襟翼加 t × PLANE[90]/100/256）。
- V < Vs + min(Vs, 146) 時 L 按比例減少（最少 160/256）。
- 機體下沉速度：vz' = 32 × (cosθ cosφ − L)，有阻尼（|v|/2，1..64 fps/s），限制於 PLANE[14..17]。側向同理。
- 所以 1G 時 vz ≈ 0；慢下來就開始沉。

### 5.9 失速（0x47B020 內）[確認]
- 狀態 0 → 1：目前 G 的包線判定「太慢」。
- 1 → 2：持續 PLANE[53]/256 秒仍太慢。
- 2：嚴重度隨時間增加（PLANE[55]），操控權降低、升力降低、機頭以 PLANE[56] deg/s 下墜、一翼下掉；PLANE[54] 時間後回到包線內則恢復。
- 尾旋（狀態 3）**未實作**。

## 7. 真實武器掛載（PT 掛點 + SH stores）

- PT 的 hardpoint 序號 = SH store 的 station 編號（`sh_editor_core.js` 的 `polys(M, {storeShown})` 把每個面標記成 store/pylon/fall）。 [確認]
- hardpoint flags：bit4 Phoenix、bit5 主動雷達、bit6 半主動、bit7 紅外線、bit8 其他飛彈、bit9 副油箱、bit10 其他外掛、bit12 不可空對空。 [確認，與 PT Editor 一致]
- loc 2 的掛點 = 機砲。
- 每個掛點可選的武器 = PT 該掛點列出的 JT，加上 flag 相容的其他 JT（`tools/jt_index.json`，181 個，由 `tools/make_jt_index.cjs` 產生）。
- 數量 = min(PT qty, 掛點載重 × 100 / JT 重量)；副油箱用 PT qty（.GAS 檔不在 repo，重量假設 2000 lb）。 [推測]
- 發射時從該 station 的 store 面重心發射，數量減 1，SH 重新以 storeShown 只畫剩下的 store，所以發射後模型上的飛彈就消失。
- 外掛重量計入總重 → 影響加速、G 限制、滾轉率（5.1、5.3、5.6）。
- 選擇會依機型存在 localStorage `fa_flight_lo_<機型>`。
