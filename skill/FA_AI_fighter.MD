# F.AI：戰鬥機 AI 行為解讀

`BI/F.AI` 是一般戰鬥機的 AI（PT 檔的 ctName 寫 `F.BI` 的飛機都用它）。F117.AI 和 MOTH.AI 是它的變體。語法和編譯方式請看 [FA_AI_BI.MD](FA_AI_BI.MD)。

標記說明：**確定** = 程式碼直接寫明；**推測** = 從用法和註解推出，還沒在遊戲裡驗證。

## 1. 執行模型

- 程式從第一行開始跑。開頭 6 行依遊戲給的「狀態」分流：`do_nothing`、`do_ir_launch`（有紅外線飛彈射向我）、`do_radar_launch`（雷達飛彈）、`do_hit`（被打中）、`do_evade`（要閃避）、`do_attack`（要攻擊）。都不是就 `exit`。
- `move`、`homePos`、`jink` 等指令是「機動」。每個指令會一直執行，直到完成（到達航向，或時間到），然後才往下一行。所以一連串 `move` 就是一段連續機動（例如 split-S、loop）。**推測**，依據是 `homeAngle 0 25 0 corner 4` 的註解寫「pop up for at least 4 seconds」，而且 loop 是用 5 個 move 串起來的。
- `restart` 表示這一輪做完了，下次再從頭判斷狀態。`exit` 表示什麼都不做，交還給遊戲。
- `maneuver "英;德;法"` 只是設定顯示用的機動名稱（目標視窗顯示 AI 正在做什麼），不影響飛行。

## 2. 技術等級與 `chance`

- `skill` 是 0..3（0 = 新手，3 = 王牌）。**確定**（`homeOnTarget` 依 0/1/2/3 設值）。
- `chance AABBCCDD` 是 8 位數，每兩位一組，依序是 skill 0/1/2/3 的成功機率 %。**推測**，但非常吻合：
  - `chance 11207484 goto bestAttack`：新手 11%，王牌 84% 會做「最佳攻擊」
  - `chance 50341406 goto random`：新手 50%，王牌 6% 會亂飛
  - `chance 52240000 goto straight`：新手 52% 直線飛（好打），skill 2、3 是 0%
- `percent N` = 不論等級，N% 機率為真。`random N` = 0..N-1。

所以等級高低不是改飛行性能，而是改「選對機動的機率」。

## 3. 各狀態的行為

### NOTHING
直接 `exit`。原本有一段「偶爾 360° 轉一圈檢查 6 點鐘」的程式，被註解掉了。

### IR LAUNCH（被紅外線飛彈追）
`move h 90 any maxspeed 5`：保持航向，拉到俯仰 +90（垂直爬升），全速，持續 5（秒）。註解寫「break toward the sun」（朝太陽爬升甩掉熱追蹤）。一半機率命令僚機 `wm_break 90 90`。

### RADAR LAUNCH（被雷達飛彈追）
- 如果目標在我側面 90° 以內（`tgtOffBeam <= 90`）：轉向目標（`hToTgt`），用最佳轉彎速度（`corner`）。
- 否則：左轉或右轉 90°（各 50%），即轉成與飛彈垂直（notch / beam 機動）。
- 兩種情況都會叫僚機 `wm_break 90 engageP`。

### HIT（被打中）
`exit`，沒有特別反應。

### EVADE（閃避）
1. 敵人是地面目標（`not tgtIsPlane`）：維持航向，爬到至少 20000 ft。
2. 30% 機率、而且敵機在後方、面向我、有僚機在戰鬥和接近時：做編隊脫離。三選一：
   - 交叉轉彎：我右轉 170°，僚機左轉
   - 左右分開：我左轉 170°，僚機右轉
   - 高低分開：我拉起 45°，僚機俯衝 45°
3. **最後手段**：敵機在正後方 5000 ft 內、面向我、航向差 ≤ 35° 時，擲 0..99：
   - <15：高度夠就 split-S
   - <35：速度差 < 50 就水平剪刀
   - <50：reverse（反向翻轉）
   - <65：條件合就 overshoot（減速讓對方衝過頭）
   - <75：loop；<85：水平 jink；其餘：垂直 jink
   - 條件不合的分支會 `goto jj0` 重新擲。
4. 敵機 30000 ft 以外：背向目標全速飛走。
5. 其他情況：垂直 jink。

### ATTACK：地面目標
- 75%：直接 `homePos 0 0 0` 飛向目標，直到水平距離 2000 ft 內。
- 25% 選「有趣的」攻擊：
  - **Dive bomb**（33%，高度和距離都夠時）：平飛接近，背飛（roll 180），垂直俯衝到剩 2 倍轉彎半徑或 2000 ft，然後拉平並反向。
  - **Pop-up**（約 2/3）：在目標上方 500 ft 低飛接近，剩 10000 ft 時以 25° 爬升 4 秒，再俯衝對準目標。
  - **Fast-high**（約 1/3）：在目標上方 5000 ft 全速通過（假設有空對地飛彈）。
- 攻擊後 **exitRun**：邊 jink 邊離開，直到離目標至少 30000 ft（或 2 倍轉彎半徑），再轉回目標，然後重新開始。

### ATTACK：空中目標
1. 叫僚機保持至少 5000 ft 水平間距。
2. **僚機包夾**：目標是戰鬥機、在我前方、僚機在 5000~30000 ft 接近中時，做以下其中一種：
   - 30%：高低分開（僚機壓低 45°，我拉起 45°）
   - 再 30%：左右包夾（bracket，各偏 45°）
3. **對玩家的偏置迎頭**：目標是玩家、距離 5000~20000、幾乎正對（`tgtOffBeam` ≤ 20、航向差 ≥ 155、俯仰差 ≤ 25），75% 機率做 offset pass（側面 8000 ft 掠過）或 overhead pass（上方 4000 ft 掠過）。
4. 離目標超過 15000 ft：直接 home on target。
5. **依相對位置決策**（依「目標在我前/後」×「目標面向/背向我」分四格）：

| 狀況 | 先擲 chance | 其他選擇 |
|---|---|---|
| 前方、面向我（迎頭） | 最佳攻擊 11/20/74/84%，亂飛 50/34/14/6% | 速度較快就 offset 分離；爬升較好就直線爬升；否則從追尾、上下追、爬升、追擊四選一 |
| 前方、背向我（我在追它） | 最佳攻擊 8/20/72/84%，亂飛 72/40/12/6% | 太快就 high yoyo，否則追擊 |
| 後方、面向我（被咬） | 最佳攻擊 16/20/72/90%，亂飛 42/20/10/4% | **新手 40% 直線飛（故意讓玩家好打）**；近距離且能爬就 loop；速度較快就分離；爬升較好就垂直剪刀；50% 垂直 jink；速度較快且高度夠就俯衝；否則從 9 種機動隨機選 |
| 後方、背向我 | 最佳攻擊 16/20/72/84%，亂飛 42/20/14/6% | 爬升好就爬；速度好就直飛拉開；否則 Immelman 或迴轉 |

- **亂飛（random）**：新手 52% 直接直線飛；否則從 16 種機動等機率選。
- **最佳攻擊（bestAttack）**：目標不是戰鬥機（轟炸機等）就直接追；如果目標緊咬在後方 2000 ft 內，75% 做最後手段閃避；否則 home on target。
- **home on target**：瞄準點偏離目標的隨機量依等級遞減：新手 0~99、skill 1 0~49、skill 2 0~29、王牌 0~9。迎頭時一半機率完全不偏。持續時間 12（5000 ft 內為 6）。

`switch random 15` 只列了 9 個標籤，`switch random 8` 只列了 2 個。**推測**：亂數超出標籤數時不跳，往下一行跑（下一行剛好都是 `goto homeOnTarget`），所以這是故意設的機率。

## 4. 機動指令參數（推測）

| 指令 | 參數 | 依據 |
|---|---|---|
| `move` | 航向, 俯仰, 滾轉(`any`=不管), 速度, 時間(0=到達即止) | `move %a 0 180 corner 1` 註解「roll over on my back」 |
| `homePos` | 相對目標 x, 高度, z, 速度, 時間 | `homePos 0 500 0` 註解「approach low」；`homePos 0 5000 0` = 高空通過 |
| `homeAngle` | 航向偏, 俯仰, ?, ?, 時間 | `homeAngle 0 25 0 corner 4` = 25° 爬升 4 秒；但僚機包夾寫成 `homeAngle 0 45 corner 0 8`，第 3、4 個參數順序不一致，還沒弄清楚 |
| `moveToAlt` | 航向, 高度, 速度, 時間 | 爬到 `%a` ft |
| `jink` | 8 個參數：航向, 俯仰, 水平幅度, 垂直幅度, ?, 次數?, 速度, 時間 | h_jink 給水平 150，v_jink 給垂直 90 |
| `yoyo` | 角度, 速度, 時間 | `yoyo 40 corner 8` |
| `immelman` / `invert` / `btoh` | | 半筋斗翻轉 / 背飛 / 「bank to horizon」改平 |
| `wm_break` / `wm_approach` / `wm_hspacing` | 給僚機（wingman）的命令 | |

速度值：`corner` = 最佳轉彎速度，`maxSpeed`，`minSpeed`，也可以寫數字。`homePos` 的速度為負（`-750`、`-1000`），可能是「與目標保持相對速度」，未確認。

值：`h`/`p`/`b` = 自己的航向/俯仰/滾轉；`hToTgt` = 指向目標的航向；`hdiff`/`pdiff`/`altDiff`/`speedDiff` = 與目標的差；`tgtAhead`/`tgtFacing` = 目標在我前方／目標朝向我；`tgtOffBeam` = 目標偏離我機頭的角度；`betterSpeed`/`betterTwr` = 我速度／推重比較好；`canClimb`；`engageP` = 交戰俯仰；`wingApproach`/`wingCombat` = 僚機狀態（wingApproach 是距離）。

## 5. 可以動手改的地方

- 讓 AI 更難：調高 `chance` 的 skill 3 欄位，刪掉「新手 40% 直線飛」那行，把 home on target 的偏移量調小。
- 讓 AI 更會躲飛彈：IR launch 現在只有垂直爬升，可以加釋放熱焰彈後俯衝的動作（要先找出投放熱焰彈的指令；目前 9 個 AI 檔都沒用到）。
- 被打中（HIT）完全沒反應，可以加脫離或迴避。
- 改完用 `python3 tools/aic.py F.AI` 編譯，把 F.BI 放進遊戲（或打進 LIB）測試。
